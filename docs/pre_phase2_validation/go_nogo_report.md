> **项目**：*QuoMech: Quotient Experimental Design for Reaction Mechanism Inference*  
> **阶段**：Phase 1（可行性探针 + 快速单 Seed 端到端 MVP 验证）  
> **硬件配置**：64 vCPU（双路 Intel Xeon Gold 6326 @ 2.90 GHz，251 GiB RAM）+ 8× NVIDIA RTX 3090（24 GB VRAM/卡，PCIe 互联）  
> **工程规范**：严格执行异构解耦——全部 `float64` 刚性 ODE / 两阶段 LM 拟合 / `Enum + BIC` 均在 64 核 CPU 的 C++17+OpenMP 编译引擎运行；8× RTX 3090 专职 BF16/FP32 神经网络与 15D 条件 NSF 训练与推理。全部机理库、化学计量表、先验与三级实验目录均 100% 数据驱动（[grammar.py](file:///home/data/jiangyi/QuoMech/quomech/grammar.py)）。

## 3. Step 3（Gate 3a）：命题 3 纯贝叶斯重要性采样（IS）小规模探针

### 3.1 诚实诊断：151 类全库盲先验 IS 的高维权重退化
先在全 151 类 × `S=2,048` 先验粒子（309,248 粒子，20 点 `σ=1%`）上跑了首次探针（[gate3a_summary.json](file:///home/data/jiangyi/QuoMech/results/gate3a/gate3a_summary.json)）：在 7–10 维连续参数空间中仅用 2,048 个盲先验粒子导致严重权重坍塌（Step 1 `ESS = 2.7–13.3`，Step 2 起 `ESS ≈ 1.0`，单粒子吃掉 99.99% 权重，反过来印证了为何必须用摊销 NPE 替代朴素 IS）。

## 4. Step 4（Gate 3b）：单 Seed 神经 MVP 训练与 E1 / E3 闭环评测

## 5. 诚实诊断与进入 Phase 2 前的 3 项关键优化建议

本次 Phase 1 Go/No-Go 验证已证明全部核心技术链路（编译型求解器、无网络五级商空间、命题 3、摊销校准、18,500× 加速与连续可变窗泛化）**全部成立**，同时也暴露出 3 个具体且完全可控的改进点，建议在 Phase 2 放大实验前落实：

1. **为什么全 151 类 E3（`T=4`）中 `Quotient EIG` 对 `Fine EIG` 的差距小于 Gate 3a？**
   - **根因诊断**：(a) 本次 MVP 仅训练 16k 步（`eff_bs=2048`），模型尚有明显收敛余量（14k→16k 步验证损失仍在下降 `10.56→10.44`），且在 `T=4` 步内只有 `24–28%` 的 151 类案例触达 `max_C q(C|D) ≥ 0.90`，使 `Fine EIG` 无法停止的浪费被 `T=4` 预算天花板截断；(b) `Step-1` 下 86% 案例因 D0 信息量太少一致首选 `D2`，导致首步分歧率仅 `~5.3%`（而 Step-2 立刻升至 `9.3%`）。
   - **Phase 2 对策**：(i) 正式模型用 `eff_bs=1024–2048` 训练至 `50k–80k` 步（支持新增的原子断点续训 `--resume`），并将数据池扩至 `10,000`/机理；(ii) 在 E3 中同时报告 `T=4` 与 `T=6`（以及 `0.85 / 0.90` 停止阈值），并针对**非平凡等价类（`|C_Ξ| ≥ 2`）**单独展示停止预算对比与类内浪费实验数曲线，让命题 3 的两重优势（选点 + 及时停止）在论文 Fig. 4 中以最清晰无截断的方式呈现。
2. **`Ξ_no-P` vs `{D0, D5}` 下 `M2` 与 `M4` 合并的论文表述微调**：
